# Nmap & Wireshark Network Defense Cheat Sheet

Commands for network scanning, service enumeration, and Wireshark display filter queries.

---

## Nmap Scan Command Matrix

```bash
# Stealth SYN Scan (Requires sudo)
sudo nmap -sS -p 1-1000 192.168.1.1

# Service Version & NSE Vulnerability Script Scan
nmap -sV --script vuln 192.168.1.1

# Ping Sweep subnet to discover live hosts
nmap -sn 192.168.1.0/24
```

---

## Wireshark Display Filters

- `ip.addr == 192.168.1.15`: Show all traffic involving IP
- `http.request.method == "POST"`: Filter HTTP POST submissions
- `dns.flags.response == 0`: Filter outgoing DNS queries
- `tcp.flags.syn == 1 && tcp.flags.ack == 0`: Show TCP SYN connection requests
