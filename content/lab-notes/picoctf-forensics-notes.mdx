# PicoCTF & OverTheWire Forensics Notes

Notes and command references used while solving CTF challenges on **PicoCTF** and **OverTheWire**.

## File Inspection & String Extraction

```bash
# Identify file type regardless of extension
file suspicious_file

# Extract printable strings searching for flag patterns
strings suspicious_file | grep -i "picoCTF{"

# Extract embedded hidden files using binwalk
binwalk -e image.png
```

## Linux Privilege Escalation & Navigation (OverTheWire Bandit)

```bash
# Find files owned by specific user or group
find / -user bandit7 -group bandit7 -size 33c 2>/dev/null

# Decode base64 strings
echo "SGVsbG8gV29ybGQ=" | base64 -d
```
