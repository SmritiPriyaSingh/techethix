## Windows Event Log IDs for Analysts

- **Event ID 4624**: Successful User Logon
- **Event ID 4625**: Failed User Logon Attempt (Brute force indicator if repeated)
- **Event ID 4672**: Special Privileges Assigned to New Logon (Admin escalation)
- **Event ID 7045**: A service was installed in the system (Persistence mechanism)

---

## Essential Splunk Search Commands

```spl
# Search for failed logons over past 24 hours
index=windows EventCode=4625 | stats count by src_ip, TargetUserName | sort - count

# Find suspicious powershell execution
index=main sourcetype="XmlWinEventLog" EventCode=1 | search CommandLine="*EncodedCommand*"
```

## Linux Auditd Command Reference

```bash
# View audit logs for authentication attempts
ausearch -m AUTH_LOGIN -i

# Monitor file modifications on /etc/passwd
auditctl -w /etc/passwd -p wa -k passwd_changes
```
