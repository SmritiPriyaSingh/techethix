# TechEthix

A clean, minimalist personal website and cybersecurity journal built with **Next.js 16**, **TypeScript**, and **Tailwind CSS**.

TechEthix serves as my digital space to document projects, cybersecurity research, lab notes, and technical write-ups while showcasing my work and learning journey.

---

## Features

- Clean, modern, minimalist UI
- Responsive design
- Personal portfolio
- Cybersecurity journal
- Lab notes
- Project showcase
- Fast performance with Next.js App Router

---

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- React
- MDX (for articles and lab notes)

## Running Locally

Clone the repository:

```bash
git clone https://github.com/SmritiPriyaSingh/techethix.git
```

Go into the project:

```bash
cd techethix
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
